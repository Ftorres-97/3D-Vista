🎬 Quick Embed

Copy and paste this code into any website to embed the 3D tour:

<iframe 
  src="https://Ftorres-97.github.io/3D-Vista/" 
  width="100%" 
  height="600" 
  style="border:none; border-radius:8px;">
</iframe>

📱 Responsive Embed

Use this code for responsive sizing that adapts to any screen:

<div style="
  position:relative; 
  width:100%; 
  padding-bottom:56.25%; 
  height:0; 
  overflow:hidden;">
  <iframe 
    src="https://Ftorres-97.github.io/3D-Vista/" 
    style="
      position:absolute; 
      top:0; 
      left:0; 
      width:100%; 
      height:100%; 
      border:none; 
      border-radius:8px;" 
    allowfullscreen></iframe>
</div>
